# 手順: 機械の点検の候補を読み直す

機械の点検は日付と有無だけで候補を出す。支援経過を読めば、問題が無いと分かることがある。
候補を1件ずつ読み直し、記録に事情や理由が書かれていれば `dismiss_candidate` で取り下げる。根拠の記録の日付と原文の語句を必ず添える。

- 訪問の無い月: 居宅を訪問できなかった特段の事情（入院中、施設への入所中、感染症での制限など）が記録されていれば取り下げる。「電話でモニタリングした」は特段の事情ではない。
- 同意日が計画の開始日より後: サービスが実際に始まったのが同意の後だと記録から分かる時、計画の開始日より前に説明や同意を得ていたと記録から分かる時は取り下げる。
- 署名の無い利用票: 署名をもらった日や、後から署名をもらった経緯が記録にあれば取り下げる。
- 書類が見当たらない: 別の場所での保管や作成の予定が記録にあれば取り下げる。

事情が書かれていない時、推測が要る時は取り下げない。迷ったら取り下げない。

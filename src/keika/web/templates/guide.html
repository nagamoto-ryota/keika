導入の前に

利用者の情報をケイカに入れる前に、事業所ですることの一覧です。紙に印刷して、済んだ物に印を付けて使えます。

この手引きは法的助言ではありません。書類の文面と決まりは事業所の責任で確かめ、必要なら専門家に相談してください。

同意書のたたき台を Word で保存する

1. 利用者と家族への説明と同意

  • □ 同意書を用意する。上のボタンで保存できるたたき台の［ ］を埋めて使えます。
  • □ 今の同意書を確かめる。個人情報の同意書がすでにあれば、追記で済む場合があります。たたき台の 1〜6 に当たる内容が今の書類にあるか、見比べてください。
  • □ 家族の分を決める。記録には家族の名前、様子、話も入るので、家族の情報にも同意が要る場合があります。たたき台に家族の署名欄があります。
  • □ 同意されない人の扱いを決める。ケイカは記録のたびに台帳の全員の名前を AI の提供元へ送り、読み取りフォルダの書類を読みます。同意されない人は、台帳にも読み取りフォルダにも入れず、ケイカの外で記録してください。後から取りやめた人は、台帳とフォルダから外します。すでに保存された記録の扱いも決めます。

3. 事業所の中の決まり

  • □ 個人情報の取扱規程に、AI の利用を追記する。
  • □ 委託先・提供先の一覧に、AI の提供元を1行足す（音声入力を使う時はその提供元も）。
  • □ 職員のルールを決める。使う端末、持ち出し、AI の下書きは人が確かめてから使うこと。
  • □ 事故の時の連絡手順を決める。誤って入れた、端末をなくした時に、誰がどこへ連絡するか。端末をなくした時は API キーも取り替えます。
  • □ 記録の保存期間と廃棄の方法を決める。データベースとバックアップの両方から消す手順にします。
  • □ 職員の退職の時の扱いを決める。端末のアカウントを止める手順、API キーの取り替え、持ち出した物の確認。

4. ケイカを動かす端末

  • □ ディスクを暗号化する（Windows の BitLocker など）。ケイカのデータベースは暗号化していない平文のファイルです。読み取りフォルダの書類と API キーの設定ファイルも同じ端末にあります。
  • □ 画面ロックを設定する。席を離れた時に他の人が見られないようにします。
  • □ 使う場所を決める。ケイカにログインはありません。開ける人は誰でも全員の情報を見られるので、職員ごとに端末のアカウントを分け、他の端末から開く設定は事業所内のネットワークに限ります。
  • □ バックアップの保管場所を決める。バックアップにも同じ情報が入るので、同じように守ります。

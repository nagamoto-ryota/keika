# 点検表の更新案: 令和6年度改定の解釈通知（老企第22号の新旧対照表）

出典: https://www.mhlw.go.jp/content/12300000/001227941.pdf

提案 9 件、2人が一致 9 件、人に回す 0 件。費用 約 $1.50。

## 2人が一致した物

- **R48 入院時に担当ケアマネの名前と連絡先を伝えてもらう依頼**: 契約の時に、入院することになったら担当ケアマネの名前と連絡先を病院に伝えてほしいと、本人か家族にあらかじめお願いします。
  - 原文: 「担当の介護支援専門員の氏名及び連絡先を当該病院又は診療所に伝えるよう、利用者又はその家族に対し事前に協力を求める」
- **R49 オンラインの担当者会議に本人・家族が出る時の同意**: 担当者会議をテレビ電話などで開き、本人や家族が参加する場合は、テレビ電話などを使うことについて本人や家族の同意をもらいます。
  - 原文: 「テレビ電話装置等の活用について当該利用者等の同意を得なければならない」
- **R50 オンライン面接の文書での同意**: 訪問しない月にテレビ電話などで面接する場合は、本人から文書で同意をもらいます。
  - 原文: 「文書により利用者の同意を得る必要があり」
- **R51 オンライン面接について関係者の合意に至った過程の記録**: テレビ電話などでの面接について、主治医・担当者などの合意をもらう時は、担当者会議でも照会でも、合意に至るまでの過程を記録します。
  - 原文: 「いずれの場合においても、合意に至るまでの過程を記録しておくことが必要である」
- **R52 対象福祉用具の貸与か購入かを選べることの情報提供**: 対象福祉用具をプランに入れる時は、貸与と購入のどちらかを選べること、それぞれのメリット・デメリットなど、選ぶのに必要な情報を本人に伝えます。
  - 原文: 「福祉用具貸与又は特定福祉用具販売のいずれかを利用者が選択できることや、それぞれのメリット及びデメリット等」
- **R53 身体的拘束等の3要件を確かめた手続きの記録**: やむを得ず身体的拘束等をする時は、切迫性・非代替性・一時性の3つの要件を満たすかを事業所として確かめ、その手続きの具体的な内容を記録します。
  - 原文: 「組織等としてこれらの要件の確認等の手続きを極めて慎重に行うこととし、その具体的な内容について記録しておくことが必要である」
- **R54 感染対策担当者を決める**: 感染対策委員会のメンバーの責任と役割分担をはっきりさせ、感染対策の担当者を決めておきます。
  - 原文: 「感染対策を担当する者（以下「感染対策担当者」という。）を決めておくことが必要である」
- **R55 利用者数に応じた介護支援専門員の配置**: 常勤のケアマネを1人以上置き、利用者数（介護予防支援の利用者は3分の1で数える）44人ごと、データ連携システムを使い事務職員を置いていれば49人ごとに1人増やします。
  - 原文: 「事務職員を配置している場合は49 人）又はその端数を増すごとに増員するものとする」
- **R56 区分支給限度額に対する割合が高いプランの届出**: プランのサービスの合計単位数が区分支給限度額に占める割合や訪問介護の割合が国の基準に当てはまる時は、その必要性をプランに書き、市に届け出ます。
  - 原文: 「当該基準に該当する場合にその必要性を居宅サービス計画に記載するとともに、当該居宅サービス計画を市町村に届け出なければならない」
